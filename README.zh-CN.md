# Wildflour 中文配方查询与加工链工具

这是一个面向中文玩家的 Wildflour 配方查询工具。

## 功能

- 中文物品名
- 中文配方描述
- 原材料查询
- 机器分类
- 冰沙 / 奶昔 / 糖果师 / 酿酒师 / 美食家配方分类
- 加工链查看
- 配方利润辅助分析

## 如何使用

打开网页后，可以通过搜索框输入中文或英文物品名，也可以按机器、分类、标签筛选。

## 数据来源

项目数据整理自 Wildflour 相关配方数据库，并进行了中文本地化与分类整理。

## 贡献

欢迎提交翻译修正、分类建议、配方补充和界面改进。
# Wildflour 中文配方工具使用说明

## 这个工具能做什么？

这个工具可以帮助 Wildflour 玩家查询物品、机器、配方、原材料和加工链。

## 适合谁使用？

- 想查中文物品名的玩家
- 想知道某个机器能做什么的玩家
- 想比较不同配方收益的玩家
- 想整理 Wildflour 高阶制作链的玩家

## 如何查询？

你可以通过以下方式查找：

- 输入中文名
- 输入英文名
- 按机器筛选
- 按分类筛选
- 按原材料查看用途

## 分类说明

### 咖啡师 / Barista

- 冰沙
- 奶昔

### 糖果师 / Confectioner

- 高级冰淇淋
- 冰淇淋三明治
- 冰棒
- 口香糖球
- 巧克力棒
- 巧克力蘸点
- 巧克力松露
- 棉花糖
- 水晶糖
- 棒棒糖与糖苹果

### 酿酒师 / Brewer

- 艾尔啤酒
- 蜂蜜酒

### 美食家 / Gourmand

- 糖浆与焦糖
- 黄油、凝乳与奶油
- 奶油奶酪
- 基础食材

## 数据更新方式

默认数据库文件是：src/data/wildflour-db.json
更新这个文件后，重新部署网站即可。
